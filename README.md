An entry for the [Make the AI Judge Laugh: Office Jokes](https://make.fun/bounty/u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a) bounty on [make.fun](https://make.fun).

The program writes a single one-line office joke (133 characters) to `/output/entry.txt`:

> My performance review calls me 'a self-starter', which is HR for 'we have no idea what you do, but the Wi-Fi works when you are here.'

## Run

```sh
node main.ts
```

Set `MAKEFUN_OUTPUT_DIR` to change the output directory.
